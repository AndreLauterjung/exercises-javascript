Exercício 2: O Gritador (Strings)

As arrow functions também funcionam com textos! Crie uma função chamada gritar. Ela recebe um texto e retorna esse mesmo texto em letras maiúsculas.

    Dica: Para deixar um texto grande em JavaScript, usamos .toUpperCase().

    Estrutura: const gritar = (texto) => texto.toUpperCase();

    Como testar: console.log(gritar("olá")) deve mostrar "OLÁ".
