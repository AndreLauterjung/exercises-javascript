Exercício: O Filtro de Preço (Iniciante)

Vamos simular um sistema de compras. Crie a função validarCompra. Ela recebe um preco e uma regra.

    A regra (arrow function) deve verificar se o preço é maior que 100.

        Dica: (valor) => valor > 100. (Isso vai retornar true ou false).

    A função validarCompra deve mostrar no console: "A compra é válida? " + o resultado da regra.
