xercício: O Calculador de Gorjeta

Imagine que você quer calcular 10% de gorjeta em um restaurante. Crie uma arrow function chamada gorjeta que recebe o valorConta e retorna quanto você deve pagar de gorjeta.

    Dica: 10% é o mesmo que multiplicar por 0.1.

    Como testar: console.log(gorjeta(200)) deve mostrar 20.
