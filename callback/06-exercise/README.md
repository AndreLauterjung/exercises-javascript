Exercício: O Conversor de Temperatura

Crie uma função chamada termometro. Ela recebe um valor em celsius e uma formula.

    A função termometro deve apenas retornar o resultado da formula(celsius).

    Crie uma Arrow Function chamada paraFahrenheit.

        A conta: (celsius * 9/5) + 32.

    Desafio: Tente guardar o resultado do termometro em uma variável chamada resultadoF e depois dê o console.log nela.
