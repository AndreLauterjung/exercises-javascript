Exercício: O Verificador de Login

Crie uma função chamada autenticar. Ela deve receber um usuario (string) e uma acao.

    A função autenticar deve dar um console.log dizendo: "Verificando usuário: [nome]".

    A acao (arrow function) deve receber o nome e retornar uma frase de boas-vindas.

    Sua Arrow Function (boasVindas): Deve retornar "Bem-vindo, " + usuario.

    Teste: autenticar("Carlos", boasVindas) deve mostrar o log e o resultado final.
