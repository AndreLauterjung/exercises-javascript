# Exercícios de JavaScript

Uma coleção de exercícios de JavaScript focados na prática de lógica e conceitos fundamentais de programação.

## Sobre

Este repositório foi criado para melhorar minhas habilidades em JavaScript por meio de exercícios práticos.  
Cada exercício foca em um conceito específico e inclui uma descrição e uma solução.

## Tópicos abordados

- Arrays
- Loops (for)
- Condicionais
- Funções

## Estrutura do projeto

Cada pasta contém:

- Um `README.md` explicando o exercício
- Um arquivo `script.js` com a solução

## Tecnologias

- JavaScript
- HTML
- Node.js

## Como executar

1. Instale o Node.js
2. Execute qualquer arquivo usando:

```bash
node path/to/script.js
```
