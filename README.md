# JavaScript Exercises

A collection of JavaScript exercises focused on practicing logic and core programming concepts.

## About

This repository was created to improve my JavaScript skills through hands-on exercises.  
Each exercise focuses on a specific concept and includes both a description and a solution.

## Topics Covered

- Arrays
- Loops (for)
- Conditionals
- Functions

## Project Structure

Each folder contains:

- A `README.md` explaining the exercise
- A `script.js` file with the solution

## Technologies

- JavaScript
- HTML
- Node.js

## How to Run

1. Install Node.js
2. Run any file using:

```bash
node path/to/script.js
```
