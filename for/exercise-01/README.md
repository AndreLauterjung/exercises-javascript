### Exercise 01

## Description

- Countdown

The `for` loop is not only used for incrementing. You can also decrement the control variable.

**Challenge:** Create a loop that starts at 10 and goes down to 0, printing each number to the console.

## Technologies

- JavaScript
- Node.js

## How to run

* Download the latest version of Node.js on your computer.

* In the terminal (such as VSCode), run the file using:

```
node path/to/script.js
```

* The result will be displayed in the terminal using `console.log`.
