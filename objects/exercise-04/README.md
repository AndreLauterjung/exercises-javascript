### Exercise 04:

Given the object below:

```js
let product = {
  name: "Notebook",
  price: 3000,
  discount: 0.1
}
```

Create a function `finalPrice` that returns the product price with the discount applied.

---

### Description

A simple JavaScript exercise to practice object creation, functions, and basic calculations.

---

### Technologies Used

* JavaScript
* Node.js

---

### How to run

* Download the latest version of Node.js on your computer.

* In the terminal (such as VSCode), run the file using:

```
node path/to/script.js
```

* The result will be displayed in the terminal using `console.log`.
