# Exercise - Product Discount

## Português (Brasil)

### Exercício:

Dado o objeto abaixo:

```js
let produto = {
  nome: "Notebook",
  preco: 3000,
  desconto: 10
}
```

Crie uma função `precoFinal` que retorne o preço do produto com desconto aplicado.

---

### Descrição

Exercício simples de JavaScript para praticar a criação de objetos e funções, além de trabalhar com cálculos básicos.

---

### Tecnologias utilizadas

* Linguagem: JavaScript
* Ambiente de execução: Node.js

---

### Como rodar

* Baixe a versão mais recente do Node.js em seu computador.

* No terminal (como o do VSCode), execute o arquivo com o comando:

```
node caminho/para/script.js
```

* O resultado será exibido no terminal através do `console.log`.

## English

### Exercise:

Given the object below:

```js
let product = {
  name: "Notebook",
  price: 3000,
  discount: 0.1
}
```

Create a function `finalPrice` that returns the product price with the discount applied.

---

### Description

A simple JavaScript exercise to practice object creation, functions, and basic calculations.

---

### Technologies Used

* JavaScript
* Node.js

---

### How to run

* Download the latest version of Node.js on your computer.

* In the terminal (such as VSCode), run the file using:

```
node path/to/script.js
```

* The result will be displayed in the terminal using `console.log`.
