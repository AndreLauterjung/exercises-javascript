# Text in English and Portuguese (Brazil)

## Português (Brasil)

### Exercício 03:

Crie uma função "apresentar" que retorna:

"Meu nome é André e tenho 20 anos"

### Tecnologias utilizadas:

- Linguagem: JavaScript
- Ambiente de execução: Node.js

### Descrição:

- Exercício simples de JavaScript para praticar a criação de objetos e funções.

### Como rodar:

- Baixe a versão mais recente do Node.js em seu computador.

- No terminal do VSCode, por exemplo, digite `node` seguido do caminho onde o arquivo `script.js` está. Exemplo:
`node Documents/exercise-03/js/script.js`
e pressione "Enter" para executar.

- O resultado do `console.log` aparecerá no próprio terminal.



## English

### Exercise 03:

Create a function "present" that returns:

"My name is André and I am 20 years old"

### Technologies Used

- JavaScript
- Node.js

### Description
Simple JavaScript exercise to practice objects and functions.

### How to run

- Download the latest version of Node.js on your computer.

- In the VSCode terminal, type `node` followed by the path where the `script.js` file is located. Example:
`node Documents/exercise-03/js/script.js`
and press "Enter" to run.

- The result of `console.log` will appear in the terminal.
