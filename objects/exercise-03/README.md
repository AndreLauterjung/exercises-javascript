### Exercise 03:

Create a function "present" that returns:

"My name is André and I am 20 years old"

### Technologies Used

- JavaScript
- Node.js

### Description
Simple JavaScript exercise to practice objects and functions.

### How to run

- Download the latest version of Node.js on your computer.

- In the VSCode terminal, type `node` followed by the path where the `script.js` file is located. Example:
`node Documents/exercise-03/js/script.js`
and press "Enter" to run.

- The result of `console.log` will appear in the terminal.
