# Exercise - Car Object

## Português (Brasil)

### Exercício:

Dado o objeto abaixo:

```js
let carro = {
  modelo: "Fusca",
  velocidade: 0
}
```

Crie as seguintes funções:

* `acelerar()` → aumenta a velocidade em +10
* `frear()` → diminui a velocidade em -10
* `status()` → exibe a velocidade atual do carro

---

### Descrição

Exercício simples de JavaScript para praticar a criação de objetos, funções e manipulação de propriedades.

---

### Tecnologias utilizadas

* Linguagem: JavaScript
* Ambiente de execução: Node.js

---

### Como rodar

* Baixe a versão mais recente do Node.js em seu computador.

* No terminal (como o do VSCode), execute o arquivo com o comando:

```
node caminho/para/script.js
```

* O resultado será exibido no terminal através do `console.log`.

---



## English

### Exercise:

Given the object below:

```js
let car = {
  model: "Fusca",
  speed: 0
}
```

Create the following functions:

* `accelerate()` → increases speed by +10
* `brake()` → decreases speed by -10
* `status()` → shows the current speed of the car

---

### Description

A simple JavaScript exercise to practice object creation, functions, and property manipulation.

---

### Technologies Used

* JavaScript
* Node.js

---

### How to run

* Download the latest version of Node.js on your computer.

* In the terminal (such as VSCode), run the file using:

```
node path/to/script.js
```

* The result will be displayed in the terminal using `console.log`.
