### Exercise 05:

Given the object below:

```js
let car = {
  model: "Fusca",
  speed: 0
}
```

Create the following functions:

* `accelerate()` → increases speed by +10
* `brake()` → decreases speed by -10
* `status()` → shows the current speed of the car

---

### Description

A simple JavaScript exercise to practice object creation, functions, and property manipulation.

---

### Technologies Used

* JavaScript
* Node.js

---

### How to run

* Download the latest version of Node.js on your computer.

* In the terminal (such as VSCode), run the file using:

```
node path/to/script.js
```

* The result will be displayed in the terminal using `console.log`.
