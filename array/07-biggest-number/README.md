### Exercise 07 - Biggest number

### Description:

Use your numbers array (you can keep the same values).

```js
const numbers = [1, 23, 21, 47, 7, 17, 422, 912, 47];
```

Create a variable called `biggestNumber` outside the for loop.

Golden tip: Start it with the first value of the array:

```js
let biggestNumber = numbers[0];
```

Inside the loop, compare the current number (`numbers[i]`) with `biggestNumber`:

IF `numbers[i]` is greater than `biggestNumber`,
then `biggestNumber` becomes this new value!

## Expected Output

```js
//The biggest number in array is: 912
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
