4. Filtro de Nomes
Crie um array convidados = ["Ana", "Bob", "Amanda", "Carlos", "Arthur"].

    Tarefa: Crie um novo array vazio chamado comecaComA. Use um for para percorrer a lista de convidados e um if para verificar se o nome começa com a letra "A". Se sim, dê um push para o novo array.

    Finalização: No final, use o .join() para exibir os nomes filtrados separados por uma seta (->).
