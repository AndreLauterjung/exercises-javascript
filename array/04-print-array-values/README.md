### Exercise 04 - Print array values

### Description:

Create an array called `numbers` with these values: `[10, 20, 30, 40, 50]`.

Use a `for loop` to iterate over this array.

Inside the loop, print: "The value of the item is: X", where X is the number at that position.

## Expected Output

```
The value of item is 10, where 0 is the number of the posicion
The value of item is 20, where 1 is the number of the posicion
The value of item is 30, where 2 is the number of the posicion
The value of item is 40, where 3 is the number of the posicion
The value of item is 50, where 4 is the number of the posicion
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
