### Exercise 01 - First and last element

### Description

Get the first and last element.

Create a function that returns the first and last items of an array.

## Expected Output

```javascript
firstLast([1, 2, 3]) //[1, 3]
firstLast([10, 20, 30, 40]) //[10, 40]
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
