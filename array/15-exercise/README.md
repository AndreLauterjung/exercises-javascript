3. O Status do Servidor
Crie um array chamado logs que armazena mensagens de erro, por exemplo: ["Erro 404", "Timeout", "Permissão Negada"].

    Tarefa: Verifique o tamanho do array (length).

        Se o array estiver vazio, exiba: "Sistema estável".

        Se tiver mensagens, use o .join() para mostrar todos os erros separados por uma barra vertical (|).
