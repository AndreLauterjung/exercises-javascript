## Exercise 09 - Loop fruit list

### Description:

Let's work with names (strings).

Create an array called fruits with: `["Apple", "Banana", "Grape", "Watermelon"]`.

Use a for loop to iterate through the list.

## Expected Output

```js
/*Fruit 1: Apple
Fruta 2: Banana
...*/
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
