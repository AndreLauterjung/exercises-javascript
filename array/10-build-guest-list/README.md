## Exercise 10 - build-guest-list

### Description:

Start with an empty guests array:

```js
let guest = [];
```

Use `.push()` three times to add three names of your friends.

Then, use a for loop to print the final list of who is going to the barbecue.

## Expected Output

```js
/*
Name 1
Name 2
Name 3
...*/
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
