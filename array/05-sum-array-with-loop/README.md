### Exercise 05 - Sum array with loop

### Description:

Create an array `numbers = [10, 20, 30, 40, 50];`

Create a variable called `sum` starting at 0 (outside the for loop).

Inside the loop, instead of just using `console.log`, add the value of the current item to the sum variable.

**Tip: Use sum = sum + numbers[i]; or the shorthand sum += numbers[i];**

At the end (outside the loops), use console.log to display the final sum.

## Expected Output

```
Sum of numbers in array: 150
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
