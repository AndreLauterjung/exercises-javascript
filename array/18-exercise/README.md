Crie três variáveis: h, m e s (coloque valores neles, tipo 9, 5 e 20).

Crie um array vazio chamado relogio.

Use if/else para cada variável:

    Se o valor for menor que 10, adicione um "0" na frente (ex: vira "09").

    Senão, apenas transforme o número em string.

Use o .push() para colocar h, m e s dentro do array relogio.

Por fim, use o .join(":") para exibir o horário.
