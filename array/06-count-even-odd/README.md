### Exercise 06 - Count even odd

### Description:

Your "Filtering" challenge:

Create an array of various numbers, Example: [12, 5, 8, 13, 21, 20, 7];

Create two "container" variables outside the loop:

let even = 0; (to count how many numbers are even)
let odd = 0; (to count how many numbers are odd)

Inside your for loop, use an if statement to test each number:

If numbers[i] % 2 == 0, increment the even counter.

Otherwise, increment the odd counter.

At the end (outside the loop), display how many even and odd numbers were found.


## Expected Output

```js
numbers = [12, 5, 8, 13, 21, 20, 7];
// Even: 4
// Odd: 3
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
