## Exercise 08 - smallest number

### Description:

Use the same array `numbers = [1, 23, 21, 47, 7, 17, 422, 912, 47];`

Create a variable called `smallestNumber` starting with `numbers[0]`.

In the loop, compare: IF the current number is less than smallestNumber,
it becomes the new smallest value.

## Expected Output

```js
//The smallest number in array is: 1
```

### Technologies

- JavaScript
- Node.js

### How to run

Download the latest version of `Node.js` on your computer.
In the terminal (such as VS Code), run the file using:

**node path/to/script.js**

- The result will be displayed in the terminal using `console.log`.
