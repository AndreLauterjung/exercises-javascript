5. Gerador de URL (Slug)
Imagine que você tem o título de um post: const titulo = ["como", "usar", "o", "metodo", "join", "em", "javascript"].

    Tarefa: Use o .join() para transformar esse array em uma URL amigável, separada por hífens (-).

    Desafio Extra: Adicione uma verificação: se a string final tiver mais de 20 caracteres, exiba um aviso no console dizendo "URL muito longa", caso contrário, exiba a URL.
